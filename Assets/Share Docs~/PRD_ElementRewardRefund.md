# 속성 획득 노드 반환

## 목표와 동작

속성 선택 노드도 기존 우클릭 1단계 반환을 허용한다. 포인트를 돌려줄 때 이 노드로 지급한 속성 1개를 회수한다. 아직 선택하지 않았으면 선택 대기만 취소한다. 기존 선행 조건과 기본 제공 단계 제한은 유지한다.

다른 경로로 얻은 동일 속성 수량은 보존한다. 회수 후 각 마법의 장착 수량이 남은 보유량을 넘으면 해당 속성 슬롯을 해제한다. 편집 사본을 먼저 보관함에 반영하여 편집 중 마법과 모든 저장 마법을 처리하고, 반환 뒤 편집기를 다시 열어 되돌리기·복사 버퍼로 회수한 모드가 복원되지 않게 한다.

보상 속성이 합성 재료로 소진되면 회수 기록을 합성 결과로 이전한다. 같은 종류의 일반 획득분을 먼저 소비하는 수량 기준을 사용한다. 합성 저장 실패 시 수량·스크랩과 함께 회수 기록도 복구한다.

## 데이터와 연결

PlayerSave의 treeElementRewardRuneId가 단일 속성 선택 노드의 지급 보상 또는 합성 결과 종류를 저장한다. RuneCodeSession의 선택 지급·합성·반환 흐름에서 이 기록을 갱신한다. 기존 저장에 기록이 없으면 보유 속성이 한 종류일 때만 회수 대상을 복원한다. 여러 종류로 모호하면 아무 것도 회수하지 않고 안내한다.

## 완료 기준

- 미선택 상태 반환은 선택 대기를 없애고 포인트를 돌려준다.
- 지급 후 반환은 재고 1개를 회수하고 남은 수량을 초과하는 장착을 모든 마법에서 해제한다.
- 다른 경로로 얻은 동일 속성과 다른 종류의 모드는 보존된다.
- 합성 후 반환, 저장 후 이어 하기, 반환 후 재구매에서도 보상이 중복으로 남지 않는다.
- 구형 저장의 모호한 보상은 임의로 삭제하지 않는다. 별도 Inspector 작업은 없다.
