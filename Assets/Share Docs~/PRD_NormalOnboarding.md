# 일반 플레이 온보딩 통합

## 목표와 범위

타이틀의 테스트 시작 버튼과 참가자 ID 입력, 별도 테스트 메모리 진행을 제거한다. 기존 테스트 온보딩 1~7장을 일반 플레이로 통합한다. 에디터 전용 디버그와 일반 플레이의 자동 익명 로그는 유지한다.

## 동작

- 새 게임에서 전투 시작, 첫 클리어, 보상 선택 후 편집창 안내, 편집창 진입, 전투 복귀, 1-3 완료 후 마법 순서, 강화 트리 안내를 기존 순서로 표시한다.
- 편집창 안내가 요구하는 방문·복귀를 마칠 때까지 다음 전투 포털을 잠근다. 첫 전투 전 실험실에서는 이 잠금을 적용하지 않는다.
- 완료한 안내 장과 요구된 편집창 방문 완료 여부를 PlayerSave에 기록한다. 이어 하기와 설정 불러오기는 이 상태를 복원하고 새 게임·진행 초기화는 초기 상태로 되돌린다.
- 기존 저장에 온보딩 기록이 없으면 첫 안내부터 시작한다. 이미 1-3 이후 진행이어도 필요한 앞선 안내를 마치면 마법 순서 안내를 표시한다.
- 종료 시점에 미완료였던 보상 선택·편집창 안내를 이어서 처리하고 이미 끝낸 안내는 반복하지 않는다.

## 연결 및 설정

TitleScreen·TitlePresenter의 테스트 진입점과 RuneCodeSession.StartTestGame을 제거한다. RuneCodeSession의 일반 온보딩 API를 MissionPresenter·MissionRun·WorkshopPresenter와 연결한다. 기존 도움말 데이터, OnboardingPopup과 2초 대기·진행선은 재사용한다. 별도 Inspector 연결은 없다.

## 완료 기준

- 타이틀에 테스트 버튼과 ID 입력창이 없고 새로 하기에서 온보딩이 표시된다.
- 일반 저장·이어 하기에서 온보딩 순서와 편집창 방문 잠금이 유지된다.
- 첫 전투 전 실험실 복귀와 1-3 이후 기존 저장에서 진행이 막히지 않는다.
- 디버그에서는 온보딩과 방문 잠금이 적용되지 않으며 일반 자동 익명 로그는 유지된다.
