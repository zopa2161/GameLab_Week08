# 단일 진행 저장과 실험실 복귀

## 목표와 범위

일반 진행을 한 개 저장으로 통합한다. 전투 도중 종료하면 마지막 완료 지점의 실험실에서 이어 하고 해당 지점 다음 전투를 다시 시작한다. 테스트·디버그의 메모리 진행과 사망·완주 시 런 초기화 규칙은 유지한다.

## 동작

- 스테이지 1-3 전투 도중 종료하면 1-2 완료 후 실험실로 복귀한다. 첫 전투 완료 전에는 첫 전투 전 실험실로 복귀한다.
- 완료 지점의 체력, 레벨·강화 포인트, 확정 획득물, 편집한 마법과 강화 상태를 기존 저장 정책대로 유지한다. 진행 중 전투의 적·투사체·피해·미확정 드롭은 복원하지 않는다.
- 미선택 보상 후보와 리롤 사용 기록은 기존 저장 내용으로 복원한다. 이어 하기 자체로 클리어 보상을 다시 지급하지 않는다.
- 타이틀 새로 하기는 기존 진행이 있으면 교체 확인 후 시작한다. 이어 하기는 선택창 없이 실험실로 진입하며 저장이 없으면 비활성화한다.
- 타이틀 저장 관리 메뉴와 슬롯 팝업을 제거한다. 설정의 기존 진행 초기화 기능을 사용하며, 불러오기는 확인 후 현재 런을 버리고 저장 지점의 실험실로 복귀한다.
- 진행 초기화·삭제는 기기 공통 소리·화면 설정을 지우지 않는다.

## 데이터와 연결

SaveStore는 runecode.progress.v4.json 한 파일에 기존 PlayerSave 형식과 암호화·원자 교체·직전 정상 파일 백업을 유지한다. 이전 활성 슬롯을 우선하고, 없으면 다른 기존 슬롯과 구버전 저장을 탐색한다. 이전 성공 후 구버전 원본은 보존하며 진행 삭제 후 자동 재이전하지 않는다. 유효하지 않거나 지원하지 않는 저장은 오류를 알리고 덮어쓰지 않는다.

RuneCodeSession.StartGame의 resumeAtLaboratory 옵션과 MissionRun의 기존 라운드 대기 복원 경로를 연결한다. 첫 완료 전 복귀는 저장 진행을 조작하지 않고 시뮬레이션을 1스테이지 0라운드 대기로 만들며 포털 진입 시 1라운드를 시작한다. 사용하지 않는 SaveSlotsPopup 코드·프리팹과 타이틀 진입점을 제거한다.

## 완료 기준

- 첫 전투와 중간 전투에서 종료 후 이어 하면 각각 첫 전투 전 실험실과 마지막 완료 지점 실험실에 나타난다.
- 보상 선택 전·후 이어 하기에서 보상·레벨·강화 포인트가 중복 지급되지 않는다.
- 복원한 실험실에서 편집기·강화 트리·허수아비·다음 전투 포털을 사용할 수 있다.
- 기존 활성 슬롯 이전, 새 진행 교체, 설정의 진행 초기화 후 재실행과 불러오기가 단일 저장 기준으로 작동한다.
