# 스크랩 기반 레벨 진행 표시

## 목표
미션 화면 맨 아래에 얇은 초록색 경험치 바 형태의 표시를 제공한다. 실제 경험치·레벨 보상·스크랩 보상 규칙을 추가하거나 변경하지 않는다.

## 동작
기존 강화 포인트 지급 라운드를 레벨업 경계로 사용한다. 다음 경계까지의 라운드 편성에서 적 수와 스크랩 보상표를 읽고 엘리트 보상 배율·분열 자식을 포함한 예상량을 계산한다. 실제로 수집한 스크랩 누계가 증가하면 현재 라운드 진행분이 채워진다. 획득량 강화는 현재 획득 배율로 정규화한다.

레벨업이 없는 라운드에서는 이전 완료 라운드의 예상 몫을 유지하고 다음 라운드가 이어 채운다. 보스 소환·증원·캐리어 등 처치 속도에 따라 가변인 추가 스크랩은 고정 예상량에 넣지 않는다. 전투 중에는 99% 이하로 제한한다. 클리어 시 잔여 스크랩과 룬을 즉시 합산하지 않고 실제 자동 회수 목록으로 옮긴다. 일반 줍기와 같은 고정 스텝 이동·도착 처리에서만 수집량과 줍기 횟수가 증가한다. 화면은 그 실제 위치를 그대로 표시하며 연출 시간이나 위치 보간으로 획득 시점을 추정하지 않는다. 마지막 스크랩 도착 후에만 해당 레벨업 구간을 100%로 표시한다. 모든 드롭 회수 후 재화·강화 포인트를 정산하고 다음 라운드 진입을 허용한다. 레벨업 연출 완료 시 0으로 초기화하고 막대 배경까지 숨긴다. 레벨업이 없는 라운드는 진행률을 유지한다. 이어하기도 저장된 라운드 경계로 표시를 복원하며 별도의 경험치 저장값을 만들지 않는다. 사망은 완료로 취급하지 않는다.

## 연결과 설정
MissionRun이 표시용 진행률을 계산하고 MissionPresenter가 MissionHud에 전달한다. MissionHud가 기존 미션 화면 아래에 입력을 막지 않는 배경·채움 이미지를 생성한다. 진행률이 0이면 채움과 배경 모두 비활성화한다. 기본 높이는 4 UI 단위이며 Inspector에서 높이·초록색·배경색을 설정할 수 있다. 추가 Prefab 연결은 없다.

## 완료 기준과 확인 결과
스크랩 수집으로 채움이 증가하고 보상 없는 라운드를 넘어 이어지며 기존 레벨업 완료 시 100%를 표시한다. 새 미션은 초기화되고 실험실·일시정지·실패로 보상을 생성하지 않는다. 현재 Unity 참조로 게임 C# 직접 컴파일 및 변경 공백 검사 통과. Unity 실제 플레이·화면 위치·Player 빌드는 아직 확인하지 않았다. 테스트 코드·자산은 추가하지 않았다.


## 실제 회수 처리 확인

게임 C# 직접 컴파일 통과. 컴파일된 LootSystem을 직접 실행해 클리어 목록 이관 시 0, 이동 중 0, 도착 시 7, 다음 스텝도 7로 유지됨을 확인했다. 이어하기는 이미 지급된 라운드 보상을 다시 지급하지 않는다. Unity 실제 플레이·화면 연출·Player 빌드는 미확인이다.
