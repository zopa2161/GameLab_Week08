# 밀어내기 상호작용 규칙

상태: 코드·룬 데이터 연결 완료. Unity Play에서의 동작 확인은 남아 있다.

## 범위

밀어내기는 공격에 맞은 적의 위치를 강제로 이동시키는 효과다. 아래에서는 다른 행동·효과·상태와 조합했을 때의 방향, 발생 시점, 우선순위만 정한다. 이동 거리·시간·감쇠·등급·비용·해금·편집 UI는 정하지 않는다.

회복·보호·적용 행동, 형태별 분기(구형·빔 형태·부채꼴), 이전 점멸 동작, 일반 전투에서 사용하지 않는 적응 감쇠는 이번 명세와 밀어내기 구현 범위에서 제외한다. 제외 항목을 위한 호환 처리나 전용 분기를 추가하지 않는다. 아래의 빔은 현재 공격 행동인 빔을 뜻한다.

## 공통 판정

- 밀어내기가 붙은 공격이 적에게 직접 적중하고 실제 체력 피해를 주었으며, 대상이 살아 있을 때 발생한다. 공격 범위에 들어왔다는 이유만으로 발생하지 않는다.
- 실제 밀어내기 거리는 등급별 기준 거리 × 이번 타격의 실제 직접 피해 ÷ 기준 피해다. 현재 기준 피해는 15이며, 피해 3인 틱은 기준 거리의 20%만 민다. 연쇄·화상 피해는 합산하지 않는다. 밀어내기 시간은 피해량과 무관하게 유지한다.
- 방향과 적중 위치는 밀기 직전의 공격 경로와 대상 위치로 정한다. 시전자에서 적을 향하는 방향을 모든 공격의 공통 기준으로 쓰지 않는다.
- 한 번의 적중 판정은 같은 적에게 밀어내기를 한 번만 발생시킨다. 여러 충돌 구간이 같은 적과 겹쳐도 중복 적용하지 않는다.
- 밀어내기는 기절이나 공격 취소를 뜻하지 않는다. 별도 규칙이 없는 한 적의 공격·재사용 대기·상태 이상은 계속 진행한다.
- 플레이어, 아군, 마법 개체, 적 발사체는 밀어내기 대상에 포함하지 않는다.

## 행동별 방향과 발생 시점

| 행동 | 밀리는 방향 | 발생 시점과 재적중 |
|---|---|---|
| 발사 | 충돌 직전 발사체의 실제 진행 방향 | 기존 적중 판정마다 한 번. 유도로 휘었다면 휘어진 뒤의 방향을 사용한다. |
| 폭발 | 폭발 기준점에서 적의 중심을 향하는 바깥 방향 | 확장 중 해당 폭발에 처음 맞았을 때 한 번. 밀려난 적이 같은 폭발에 다시 들어와도 추가로 밀지 않는다. |
| 잔류 | 해당 피해 판정 시점의 영역 기준점에서 적의 중심을 향하는 바깥 방향 | 예고 중에는 발생하지 않는다. 기존 지속 피해 간격마다 다시 밀 수 있으며, 범위를 벗어나면 멈춘다. |
| 빔 | 적중한 빔 구간의 진행 방향. 직선은 발사 방향, 곡선은 맞은 지점의 접선 방향 | 기존 빔 피해 판정마다 한 번. 대상별 두 번째 피해마다 발생하는 적중 이벤트와 별개로, 매 유효 피해에서 밀어낸다. |

폭발·잔류는 해당 공격의 생성 기준점을 사용한다. 이동하는 영역은 적중 당시의 기준점을 사용한다.

폭발·잔류의 기준점과 적 중심이 정확히 같으면 해당 공격의 현재 방향을 사용한다. 그 방향도 없으면 밀어내기를 생략하며 무작위 방향을 만들지 않는다.

### 빔의 경로가 복잡할 때

- 유도 빔은 적과 접촉한 구간의 시작점에서 끝점으로 향하는 방향을 사용한다. 빔의 최초 조준 방향이나 빔에서 수직으로 멀어지는 방향을 사용하지 않는다.
- 공전 빔은 원형 경로의 진행 방향을 따라 접선으로 민다. 공전 중심에서 바깥쪽으로 밀지 않는다.
- 같은 적이 여러 구간에 겹치면 경로 시작점부터 가장 먼저 접촉하는 구간 하나를 선택한다. 접촉 순서가 같으면 경로 구간 순서로 정한다.
- 빔이 다시 계산되면 다음 피해 판정은 새 경로의 방향을 사용한다. 이미 시작된 밀어내기의 방향을 계속 회전시키지는 않는다.
- 예: 오른쪽으로 발사한 빔이 위로 휘어 적을 맞혔다면 그 적은 위로 밀린다. 직선 빔이 오른쪽으로 지나가면 적도 오른쪽으로 밀린다.

## 효과 모듈과의 조합

| 조합 대상 | 상호작용 규칙 |
|---|---|
| 유도 | 적중 순간의 실제 경로를 반영한다. 밀어내기 자체가 대상을 추적하지는 않는다. |
| 공전 | 발사 행동은 공전 궤도의 실제 이동 방향, 폭발·잔류는 각 개체의 영역 기준점, 빔 행동은 빔 경로의 접선을 사용한다. |
| 다중 | 생성된 각 공격이 독립적으로 밀어낸다. 같은 틱의 중첩은 아래 중복 규칙을 따른다. |
| 관통 | 관통한 각 적을 해당 적중 방향으로 민다. 밀어내기로 관통 횟수를 추가 소비하지 않으며, 관통 피해 감소는 기존대로 적용한다. |
| 효과 증폭 | 기존 피해 증폭은 유지한다. 실제 직접 피해가 증가한 비율만큼 밀어내기 거리도 증가한다. |
| 확장 | 커진 판정 범위에 맞는 대상도 같은 규칙으로 민다. 크기 배율이 밀어내기 거리를 자동 변경하지 않는다. |
| 속도 | 발사·공전·빔 경로 등 기존 속도 효과는 유지한다. 빨리 움직인다는 이유로 더 멀리 밀거나 별도 밀기 판정을 추가하지 않는다. |
| 지속시간 | 공격이 유지되는 동안 기존 재적중 조건에 따라 밀 수 있다. 한 번의 밀어내기 시간이나 거리를 자동 연장하지 않는다. |
| 지연·반복·조건 | 실제로 실행되어 적중한 공격에만 적용한다. 반복으로 새로 생성된 공격은 독립된 공격으로 취급한다. |
| 마법 메소드 호출 | 기존 효과 전달 범위에 따라 밀어내기를 받는 공격에만 적용한다. 호출했다는 이유로 내부·외부의 모든 공격에 전역 적용하지 않는다. |

## 속성·피해·방어와의 조합

| 조합 대상 | 상호작용 규칙 |
|---|---|
| 일반·화염 | 직접 공격 적중에는 적용한다. 화상 등 이후의 속성 지속 피해는 추가 밀어내기를 발생시키지 않는다. |
| 냉기 감속 | 적의 자발적 이동만 느려진다. 밀어내기 거리나 진행 속도를 감속시키지 않는다. |
| 빙결 | 빙결 중인 적은 밀어내기에 면역이다. 이번 적중으로 빙결되는 경우에도 밀지 않는다. 빙결 해제 뒤의 새 적중부터 다시 적용한다. |
| 전격·EMP | 직접 맞은 대상만 민다. 전격의 연쇄 피해에는 밀어내기를 복제하지 않는다. EMP 자체는 밀어내기 면역이나 증폭을 만들지 않는다. |
| 방패의 피해 감소 | 감소 후 실제 체력 피해가 남으면 밀어낸다. 감소 후 실제 직접 피해에 비례해 밀어내기 거리도 줄어든다. |
| 공격을 차단하는 방패 | 공격이 방패에 막혀 체력 피해가 없으면 방패 소유자를 밀지 않는다. 기존 방패 충돌 이벤트는 유지한다. |
| 무적·패칭·완전 피해 차단 | 실제 체력 피해가 없으면 밀지 않는다. |
| 처치·분열 | 이번 피해로 죽은 적은 밀지 않는다. 사망 위치·분열 위치를 밀어내기로 옮기지 않으며 자식에게 부모의 밀어내기를 상속하지 않는다. |

## 적 행동·이동·충돌과의 조합

- 보스는 밀어내기에 면역이다. 일반 적과 엘리트는 크기나 등급만으로 추가 면역을 얻지 않는다.
- 돌진 중인 적은 밀어내기에 면역이다. 돌진 예고 중인 적은 밀 수 있지만, 예고나 예정된 돌진을 취소·재시작하거나 방향을 바꾸지는 않는다.
- 빙결·돌진·보스의 면역은 기존 적 겹침 분리에서 고정 대상으로 취급하는 기준과 맞춘다.
- 일반 추적·거리 유지·정지형 적도 면역 조건에 해당하지 않으면 밀 수 있다. 이동하지 않는 행동과 강제 이동 면역을 같은 뜻으로 취급하지 않는다.
- 밀어내기 이동 중에는 자발적 이동을 잠시 보류하고, 종료하면 기존 이동 행동을 다시 따른다. 공격과 소환의 시간 진행은 유지한다. 적의 바라보는 방향을 밀리는 방향으로 강제 회전시키지 않는다.
- 벽·맵 경계는 통과하지 않는다. 막힌 지점에서 밀어내기를 끝내고 반사·추가 충돌 피해·벽을 따른 미끄러짐은 발생시키지 않는다.
- 다른 적에게 밀어내기를 전달하거나 충돌 피해를 주지 않는다. 겹침은 기존 적 분리 규칙으로 처리하며 밀어내기 효과를 복제하지 않는다.
- 밀리는 적이 플레이어와 접촉하면 기존 접촉 피해 규칙을 따른다. 밀어내기만으로 접촉 면역을 부여하지 않는다.
- 시전자의 이동·대시은 이미 시작된 밀어내기의 방향을 바꾸지 않는다. 시전자를 따라가는 공격은 다음 적중 시점의 위치·경로로 새 방향을 정한다.

## 여러 공격이 겹칠 때

- 같은 틱에 같은 적을 미는 유효 적중들은 밀어내기 벡터를 합쳐 한 번 적용한다. 반대 방향은 상쇄되고, 대각 방향은 합성된다.
- 합성 결과의 크기는 그 틱에서 가장 강한 단일 밀어내기 크기를 넘지 않는다. 다중 공격만으로 이동량이 무제한 증가하지 않게 한다.
- 밀리는 도중 다른 틱에 새 밀어내기를 받으면 새 판정 결과로 방향과 남은 밀기를 교체한다. 이전 밀기를 대기열에 쌓지 않는다.
- 적용 도중 빙결되거나 돌진을 시작하는 등 위에서 정한 밀어내기 면역 조건이 성립하면 남은 밀기를 즉시 종료한다. 단순 피해 면역 전환은 이미 시작된 이동을 취소하지 않으며 새 밀기만 차단한다.

## 적중 이벤트·후속 공격

- 밀어내기 자체는 적중·소멸·피격 이벤트를 추가로 발생시키지 않는다. 벽이나 다른 적에 부딪혀도 추가 이벤트가 없다.
- 기존 공격의 피해·속성·이벤트 판정은 유지한다. 발사·폭발·빔의 기존 적중 이벤트 발생 횟수를 밀어내기 때문에 바꾸지 않는다. 잔류에 새 적중 이벤트를 만들지 않는다.
- 한 피해 판정에서는 적중 위치·방향·후속 이벤트 문맥을 먼저 확정하고, 피해와 속성을 처리한 뒤 밀어내기를 확정한다. 후속 공격의 생성 위치를 밀린 뒤의 적 위치로 바꾸지 않는다.
- 적중 이벤트로 생성된 후속 공격은 자신의 행동·전달받은 효과에 따라 새로 판정한다. 부모에게 밀어내기가 있다는 이유만으로 자동 상속하지 않는다.
- 같은 틱의 적중 대상 선정에는 아직 적용하지 않은 밀어내기 이동을 반영하지 않는다. 밀어서 공격 범위에서 빠져나가는 효과는 이후 판정부터 반영한다.

## 규칙 확인 사례

| 사례 | 기대 결과 |
|---|---|
| 유도 발사체가 적의 옆으로 돌아 적중 | 시전자 방향이 아닌 충돌 직전 진행 방향으로 이동 |
| 휘어진 빔·공전 빔에 적중 | 맞은 구간의 접선 방향으로 이동, 한 피해 판정에 한 번만 발생 |
| 폭발 중심의 양옆 적에게 적중 | 각각 폭발 기준점에서 멀어지는 반대 방향으로 이동 |
| 잔류에 들어온 적이 밀려 범위 밖으로 나감 | 기존 간격으로 밀다가 범위를 벗어난 뒤에는 피해·밀기 중단 |
| 냉기 공격이 이번 적중으로 빙결 부여 | 피해와 빙결은 적용되고 밀어내기는 발생하지 않음 |
| 전격 직접 적중과 연쇄 피해 발생 | 직접 적중 대상만 이동 |
| 방패 차단·처치·돌진 중 적중 | 각 기존 피해·이벤트 규칙은 유지하며 밀어내기는 발생하지 않음 |
| 같은 틱에 정반대의 동일한 밀기 적중 | 피해는 각각 처리하고 밀어내기는 상쇄 |
| 적중 후속으로 폭발 생성 | 기존 접촉 위치에서 폭발하고 자체 밀어내기 보유 여부에 따라 판정 |

## 구현 연결과 임시 설정

- 효과 ID는 `mod.knockback`이다. 기존 행동 슬롯과 마법 메소드 호출의 효과 전달 경로를 사용한다. 엘리트 효과 드롭·선택 보상의 기존 등급별 후보 목록에도 포함된다.
- 밀어내기는 시작 룬으로 분류하며 해금 트리 노드가 없어도 사용한다. 새 저장과 기존 저장 모두 최저 등급 C 1개 이상을 보장하며, 이미 보유한 수량은 줄이지 않는다.
- 거리 기본값과 시간은 `tables/runes.json`의 `_knockbackDistance`·`_knockbackSeconds`·`_knockbackReferenceDamage`에서 관리한다. 등급별 거리는 `tables/elite_modifier_drops.json`의 `knockbackDistance`에서 관리한다.
- 피해 15 기준 임시 거리: C 60px / B 90px / A 120px / S 180px. 시간은 전 등급 0.2초다. 임시 비용은 RAM 1, 기존 마나 비용 배율 1.2다. 최종 밸런스 수치는 아니다.
- 같은 공격에 호출부와 직접 장착 효과가 겹치면 거리는 최댓값을 사용하며 중복 곱셈하지 않는다. 시간도 최댓값을 사용한다.
- 적이 공통 강제 이동 예약과 진행 상태를 소유한다. 공격은 방향·거리·시간만 전달하며 새 Manager나 상태 머신을 추가하지 않는다.
- 모든 적중·후속 이벤트가 기존 위치를 사용하도록 예약된 밀기는 다음 시뮬레이션 틱부터 이동한다. 동일 틱 벡터 합성 후 가장 큰 단일 거리로 제한하며, 완전히 상쇄되면 기존 밀기도 종료한다.
- 회복·보호·적용·형태별 전용 처리와 미사용 기능의 호환 분기는 추가하지 않았다. Scene·Prefab·Inspector 참조를 새로 연결할 필요는 없다.

## 검증과 남은 확인

- Core와 전체 게임 C# 프로젝트 컴파일 통과. 전체 게임에는 기존 `SpellEditorPanel.TutorialClicked` 미사용 이벤트 경고 1건이 있다.
- 기존 룬 카탈로그·효과 등급 로더로 JSON 검증 통과. 밀어내기 C/B/A/S 등록과 현지화 키 중복 없음 확인.
- 별도 Unity 일괄 실행은 프로젝트를 연 상태에서 초기 종료되어 가져오기·Play 검증으로 인정하지 않았다. 빌드 실행 파일도 새로 만들지 않았다.
- Unity에서 스크립트 반영과 Console 오류 유무를 확인한다. 밀어내기를 획득한 뒤 발사·폭발·잔류·빔의 기존 효과 슬롯에 장착하고 위 규칙 확인 사례를 시험 도크와 미션에서 확인한다. 유도·공전 빔, 벽, 빙결·돌진, 반대 방향 중첩, 후속 공격 위치, 전투 종료 후 재입장도 확인한다.
- 저장소 전체 변경 상태와 예상 밖 자산 변경 여부는 Diff·에디터 Git 화면으로 확인하지 못했으므로 미확인이다.
